# translate.js

#### AI i18n — автоматический перевод HTML-страниц в две строки на JavaScript. Без правки вёрстки, без языковых конфигов, без API-ключей и с полной поддержкой SEO!

## Основные возможности

* **Максимально простое подключение.** Достаточно добавить пару строк JavaScript-кода, чтобы сайт получил поддержку более 100 языков. Не нужно переписывать вёрстку, заводить JSON-словари или регистрироваться на сторонних сервисах для получения API-ключей — скрипт сам сканирует DOM и переводит текст.
* **Гибкая настройка и расширяемость.** Можно переводить только выбранные блоки страницы, настраивать внешний вид переключателя языков, исключать из перевода элементы по `id`, `class` или тегу, задавать собственный словарь терминов, а также автоматически определять язык посетителя по настройкам браузера и стране.
* **Высокая скорость работы.** Многопоточная обработка, трёхуровневое кэширование, предзагрузка и очистка текста обеспечивают практически мгновенный перевод.
* **Полностью бесплатно и Open Source.** Распространяется по лицензии MIT — библиотеку можно свободно использовать в любых проектах, включая коммерческие продукты и браузерные расширения.
* **Дружелюбность к SEO.** Скрипт не изменяет исходный HTML-код страницы, который видят поисковые роботы, поэтому индексация сайта в поисковиках не страдает.
* **Поддержка приватного развёртывания (On-Premise).** Для закрытых корпоративных контуров, госструктур и проектов без доступа в интернет можно развернуть собственный сервер перевода.
* **Глобальная сеть узлов.** Узлы в Европе, Азии и Америке автоматически тестируются каждую минуту, выбирая сервер с минимальной задержкой.

## Быстрый тест на любом сайте

1. Откройте любую веб-страницу в браузере.
2. Нажмите правой кнопкой мыши → **Просмотреть код (Inspect)** и перейдите во вкладку **Console**.
3. Вставьте следующий код и нажмите **Enter**:
   ```javascript
   var head = document.getElementsByTagName('head')[0];
   var script = document.createElement('script');
   script.type = 'text/javascript';
   script.src = 'https://zvo.cn';
   head.appendChild(script);
   ```
4. В левом верхнем углу страницы появится меню выбора языка.

**Онлайн-демо:** http://zvo.cn

## Подключение к проекту

Добавьте следующий код в конец вашей HTML-страницы перед закрывающим тегом `</html>`:

```html
<script src="https://zvo.cn"></script>
<script>
    // Указываем исходный язык страницы (если не задавать, определится автоматически)
    translate.language.setLocal('russian'); 
    // Выбираем канал машинного перевода (подробнее: http://zvo.cn)
    translate.service.use('client.edge'); 
    // Включаем отслеживание динамически добавляемых элементов (для SPA / AJAX)
    translate.listener.start(); 
    // Инициализируем и запускаем перевод
    translate.execute(); 
</script>
```

## Ключевые настройки и API

* **Кастомизация переключателя языков:** изменение позиции, стилей CSS, списка доступных языков и обработчиков событий.
* **Язык по умолчанию:** автоматическое переключение на язык браузера/страны пользователя при первом визите или принудительный выбор языка.
* **Словарь терминов:** переопределение перевода для специфических слов, брендов или технических терминов.
* **Фильтрация элементов:**
  * перевод только указанных элементов;
  * игнорирование элементов по `id`, `class`, HTML-тегу или регулярному выражению;
  * перевод атрибутов тегов (например, для компонентов Vue/Element).
* **Работа с динамическим контентом:** автоматический перехват изменений DOM (Vue, React) и завершённых AJAX/Fetch-запросов.
* **Устранение мерцания при загрузке:** скрытие исходного текста до завершения перевода, чтобы пользователь сразу видел переведённую страницу.
* **События жизненного цикла:** хуки до отправки запроса к API и после завершения рендеринга перевода в DOM.
* **Собственный бэкенд перевода:** возможность подключить свой API-шлюз или локально развёрнутые LLM (Qwen3, GLM, DeepSeek и др.) через `translate.service.use`.

## Расширения и экосистема

* **Браузерное расширение:** готовый шаблон плагина для браузера с возможностью кастомизации под свой бренд.
* **HTML Translation API:** серверный перевод сырого HTML-кода с сохранением структуры документа.
* **Приватный сервер перевода (On-Premise):** разворачивается на Linux, поддерживает кэширование в памяти, многопоточность и подключение локальных нейросетей.
* **Модель `translate100`:** компактная seq2seq-модель на Hugging Face ([xnx3/translate100](https://huggingface.co)), способная работать на слабом железе (1 CPU / 2 ГБ RAM) полностью офлайн.
